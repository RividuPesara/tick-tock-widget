# Desktop Clock Widget

A desktop clock widget built with Electron, featuring a retro pixel art aesthetic and a clean interface.

## Features

- **Real-time clock** - Displays current time in HH:MM format
- **Date display** - Shows current month and day
- **Pixel art design** - Custom retro style UI with gradient backgrounds
- **Transparent window** - Frameless design with rounded corners
- **Draggable** - Move the widget anywhere on your desktop
- **Lightweight** - Minimal resource usage
- **Auto-updates** - Time refreshes automatically every minute

## Installation

1. Clone this repository:
```bash
git clone https://github.com/RividuPesara/tick-tock-widget
cd tick-tock-widget
```

2. Install dependencies:
```bash
npm install
```

3. Run the application:
```bash
npm start
```

## Technologies Used

- **Electron** - Desktop application framework
- **HTML/CSS/JavaScript** - Frontend
  
This project was built by following **[Nashallery](https://www.youtube.com/watch?v=btxGSJ3Dh8E)**'s YouTube tutorial for creating a calendar frame, and then transformed into a functional clock widget with additional features.
